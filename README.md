# ai-drom-management
AI-based dormitory management system using Django and DRF
基于 Django + DRF + UniApp 的智能宿舍管理系统，
支持AI风险预警、违规检测、整改建议生成等功能。
后端：
- Django
- Django REST Framework
- Channels

前端：
- UniApp(Vue)

AI：
- DeepSeek
- 豆包大模型
- 蓝心大模型

数据库：
- SQLite（或 MySQL）

功能模块：
- - 用户登录认证
- 宿舍管理
- 请假管理
- AI整改建议
- 风险预警
- 周报生成

本人负责：
- Django后端开发
- DRF接口设计
- AI模块接入
- 风险预警逻辑
- 数据模型设计
